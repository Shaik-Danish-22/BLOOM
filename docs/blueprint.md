# **App Name**: FounderOS AI

## Core Features:

- Cinematic Agent Orchestration: A visually immersive multi-agent sequence simulating a coordinated startup team building market intelligence tool by tool.
- The Oracle Score: An animated SVG gauge providing an investor score with count-up animations and glowing data visualizers.
- Strategic Founder Dashboard: A high-fidelity cockpit displaying TAM/SAM/SOM charts, competitor maps, and automated GTM strategy cards.
- Interactive Investor Simulator: A simulated pressure-test interview where users respond to AI agent 'hardball' questions to refine their pitch.
- Reliable Demo Architecture: A specialized 'Demo Mode' that bypasses real-time calls to provide a rock-solid, choreographed visual experience for presentations.
- Startup Persistence Layer: Secure storage of generated company data and investor chat history using Firestore for fast, anonymous retrieval.

## Style Guidelines:

- Primary color: Radiant Violet (#9F5CF0) to evoke a sense of future-tech luxury and intelligence.
- Background: Midnight Obsidian (#08070B), providing a deep, cinematic canvas for glassmorphic elements.
- Accent: Electric Indigo (#606CFF) used for CTAs and critical investor scores to provide a punchy high-contrast glow.
- Headline font: 'Instrument Serif' for a prestigious, editorial look; Body font: 'Inter' for functional UI precision.
- Thin-stroke 'lucide-react' icons paired with purple ambient glows for a lightweight, sophisticated feel.
- Apple-grade spatial awareness using a vertical bento-grid structure for the startup dashboard.
- Shared-element transitions using Framer Motion to move seamlessly from input to company generation.
