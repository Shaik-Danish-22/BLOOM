## Vision

BLOOM is a **generative intelligence platform** that orchestrates multi-agent AI reasoning to synthesize startup identities, strategic positioning, and cinematic user experiences from raw ideas.

We believe great startups aren't built—they're *orchestrated*.

### What Makes BLOOM Different

- **Neural DNA Engine**: Derives core strategic and visual identity from vague ideas through elite startup reasoning
- **Multi-Provider Orchestration**: Seamlessly routes tasks across DeepSeek reasoning, Gemini reasoning, and fallback systems for production reliability
- **Anti-Slop Validation**: Editorial magazine-grade content generation that rejects generic AI filler
- **Cinematic Materialization**: Transforms abstract startup concepts into immersive visual experiences with synchronized motion design
- **Investor Simulation**: Pressure-tests founder pitches through AI-powered market analysis and hardball questioning
- **Design DNA Architecture**: Generates comprehensive brand systems including typography, color psychology, motion philosophy, and interaction patterns

## How It Works

### 1. **Idea Capture**
Founders input raw, unrefined startup concepts through a natural language interface.

### 2. **Neural DNA Derivation**
The **Design DNA Engine** processes the idea through multiple reasoning chains:
- Strategic positioning analysis
- Market opportunity assessment
- Brand identity synthesis
- Design system generation
- Investor-grade scoring

### 3. **Multi-Provider Orchestration**
Tasks are intelligently routed across:
- **DeepSeek** (via Featherless/OpenRouter): Complex reasoning and strategic analysis
- **Gemini 2.5 Flash**: Fast content generation and real-time inference
- **Fallback Systems**: Automatic failover for production resilience

### 4. **Cinematic Materialization**
Generated intelligence transforms into:
- Immersive workspace dashboards
- Animated visualizations and gauges
- Interactive investor simulations
- Strategic content presentations

### 5. **Persistent Storage**
Startup data persists via Firestore for:
- Workspace recovery and continuation
- Investor chat history
- Multi-session iteration
- Team collaboration

## Quick Start

### Prerequisites

- **Node.js** 18+ (v20 recommended)
- **npm** or **yarn** package manager
- **Firebase Project** with Firestore and Authentication enabled
- **API Keys**: DeepSeek (via OpenRouter) and Google Genkit credentials

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/bloom.git
cd bloom

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Configure your API keys in .env.local
# See SETUP_GUIDE.md for detailed instructions
```

### Environment Configuration

Create a `.env.local` file in the project root:

```bash
# Google Genkit Configuration
NEXT_PUBLIC_GOOGLE_GENAI_API_KEY=your_google_genai_api_key

# Firebase Configuration
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id

# DeepSeek Reasoning (via OpenRouter)
OPENROUTER_API_KEY=your_openrouter_api_key
OPENROUTER_MODEL=deepseek/deepseek-r1

# Fallback Providers
FALLBACK_AI_MODEL=googleai/gemini-2.5-flash
```

For a complete setup guide, see [SETUP_GUIDE.md](./docs/SETUP_GUIDE.md).

### Development

```bash
# Start the Next.js development server
npm run dev

# In a separate terminal, start the Genkit AI development environment
npm run genkit:dev

# Open browser to http://localhost:9002
```

Both servers will hot-reload on file changes.

### Production Build

```bash
# Type checking
npm run typecheck

# Create optimized production build
npm run build

# Start production server
npm start
```

## AI Orchestration: Under the Hood

### Multi-Provider Routing Strategy

BLOOM implements intelligent task routing across multiple AI providers for **production reliability** and **specialized reasoning**:

#### Primary Provider: DeepSeek (Featherless/OpenRouter)
**Best for**: Complex reasoning, strategic analysis, long-form synthesis
- Strategic positioning derivation
- Market opportunity analysis
- Competitive moat identification
- Risk assessment

#### Secondary Provider: Gemini 2.5 Flash
**Best for**: Fast inference, real-time content generation, fallback
- Hero section generation
- Quick market summaries
- Investor question generation
- Response evaluation

#### Fallback Systems
**Strategy**: Automatic downgrade to ensure system resilience
- Gemini → Claude → Llama (configurable)
- Transparent error handling with user feedback
- Graceful degradation without data loss

### Genkit Flow Architecture

Each AI task is wrapped in a Genkit flow with:
- **Input schema validation** (Zod)
- **Multi-provider routing logic**
- **Output schema enforcement**
- **Error handling and fallbacks**
- **Observability logging**

Example:
```typescript
export async function deriveDesignDNA(input) {
  try {
    // Try primary reasoning provider
    return await orchestrateTask({
      task: 'reasoning',
      schema: DeriveDesignDNAOutputSchema,
      // ... provider config
    });
  } catch (error) {
    // Fallback to Gemini with simplified prompt
    return await geminiDerivedDNA(input);
  }
}
```

For detailed technical documentation, see [AI_ORCHESTRATION.md](./docs/AI_ORCHESTRATION.md).
